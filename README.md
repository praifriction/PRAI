# PRAI Framework v0.1

PRAI is a four-dimensional heuristic for analyzing social systems through Power, Resources, Affect, and Institutions, designed to reduce oversimplified conclusions while preserving uncertainty and ethical boundaries.

## Versions

- **PRAI Light** — quick scan for low-friction first-pass analysis.
- **PRAI Medium** — structured analysis for general social/systemic questions.
- **PRAI Full** — high-stakes audit and action check for complex or sensitive cases.

## Core Dimensions

- **P / Power** — authority, coercion, leverage, decision rights.
- **R / Resources** — money, labor, time, attention, infrastructure, information.
- **A / Affect** — emotion, social pressure, fear, anger, shame, belonging, desire.
- **I / Institutions** — rules, norms, procedures, incentives, constraints.

## Safety Boundary

PRAI is an analytic tool, not a moral verdict, excuse, or replacement for lived emotion.

Use it to clarify systems, not to justify domination, paranoia, or self-validating conclusions.
